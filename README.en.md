# Time Ticket Control

Language: [Português (Brasil)](README.md) | **English**

This project was created to help my wife organize the mandatory time-clock ticket record process.

The idea came up because the company still could not ensure a reliable digital clock-in workflow without the need to save a photo of the ticket every time the clock-in is registered.

## Goal

- Centralize time ticket records and tracking.
- Make daily proof-of-registration easier.
- Reduce the risk of losing important records for later checking.

## PWA

This project has **PWA (Progressive Web App)** support configured, allowing practical mobile usage and quick access as if it were an installed app.
