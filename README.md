# Controle de Ticket de Ponto

Idioma: **Português (Brasil)** | [English](README.en.md)

Este projeto foi criado para tentar auxiliar minha esposa a organizar a obrigatoriedade do registro de ticket de ponto.

A ideia nasceu porque a empresa ainda não conseguiu garantir que o ponto digital funcione de forma confiável sem a necessidade de salvar uma foto do ticket toda vez que o ponto é batido.

## Objetivo

- Centralizar o registro e o acompanhamento dos tickets de ponto.
- Facilitar a rotina diária de comprovação de marcação.
- Reduzir riscos de perda de informações importantes para conferência posterior.

## PWA

Este projeto está com **PWA (Progressive Web App)** configurado, permitindo uso mais prático no celular e acesso rápido, como se fosse um aplicativo instalado.

## O que pode ser melhorado ainda

Lista de melhorias e ideias para lembrar depois:

- Permitir excluir fotos enviadas.
- Agrupar fotos por mês para facilitar consulta.
- Deixar a senha mais simples (sem comprometer segurança).
- Otimizar o upload de imagens (velocidade e estabilidade).
- Permitir compartilhar registros com outros usuários.

### Outras opções de auxílio (futuras)

- Criar filtros por período (semana, mês, ano).
- Adicionar busca por data e horário do ponto.
- Exibir status de envio (pendente, enviado, erro).
- Permitir exportar relatórios (PDF/Excel).
- Criar lembretes para não esquecer de registrar o ponto.
